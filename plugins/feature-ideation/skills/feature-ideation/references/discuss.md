# discuss — 既存アイデアを 1 件深掘りする

`/feature-ideation discuss FI-012` で起動する。vault にある 1 件を Q&A で詰め、
結果をインラインの備考更新か詳細ファイルへの昇格として永続化する。

## 手順

### 1. 対象を特定する

vault index を Read し、ID の行を探す。見つからなければ
「ID `FI-012` は vault にありません。`/idea-check` で一覧を見るか、引数なしで新規追加してください」
と案内して**中止する**（似た ID を勝手に選ばない）。

詳細ファイル（`<feature-ideas>/FI-012*.md`）があれば Read する。ファイル名は `FI-012.md` とは限らないので
Glob で `FI-012*` を探すこと。

### 2. Q&A で詰める

聞くのは以下。**全部聞く必要はなく、その ID にとって効く 2〜3 個に絞る**。
選択肢が立てられるものは `AskUserQuestion` を使う。

- **昇格条件 / 却下条件** — `⚠️` なら「何が起きたら ✅ になるか」。`✅` なら「何が起きたら ❌ に落ちるか」
- **実装の入口** — 最初に触るファイル・関数はどこか
- **影響範囲** — 破壊的変更の有無、移行戦略
- **比較対象** — 類似 OSS や過去の自プロジェクトでの判断
- **検証方法** — どうやって「うまくいった」と判断するか

**外部の事実（他ツールの機能・ベンチマーク値）を扱うときは、その場で WebSearch / WebFetch で裏を取り
URL を残す。** 記憶から書かない。確認できなければ「未確認」と明示する。
vault は長期参照される資産で、しかもアイデアという性質上あとから検証されにくい。ここで混入した誤りは長く残る。

### 3. インラインか昇格かを判定する

基準は [`evaluation.md`](evaluation.md)。要約すると、1 行（〜80 字）に収まるなら備考を更新するだけ。
論点・条件分岐・複数 URL・コード断片が要るなら詳細ファイルへ昇格する。

### 4. 永続化する

**インラインで済む場合**: index のテーブル行を Edit で更新する。備考は最新の一行要約に**上書き**してよい。

**詳細ファイルへ昇格する場合**:

1. `<feature-ideas>/FI-NNN.md` を Write（既存なら Edit で追記）。frontmatter と本文の書式は
   [`evaluation.md`](evaluation.md) の「詳細ファイルの書式」に従う
2. **議論の結果は `## 判定履歴` に日付つきで追記する**（備考には積まない）
3. index の備考を「一行要約 + 詳細ファイルへのリンク」に置換する
4. index の状態を `probing` にする
5. 詳細ファイルの `updated` を今日の日付にする

**日付の期限が出てきた場合**（「N 週間後に再評価する」等）:

- 日付に落とせるなら vault の `## 再評価キュー` に行を足す。
  **`何を判定するか` を必ず書く**（日付だけの期限はその日が来ても何を決めるか分からず腐る）
- 「〜が出たら」「〜の検証後」のように**外部条件でしか判断できないなら、vault に書かない**。
  [`archive.md`](archive.md) の「条件トリガの隔離」に従って `known-issues.md` 等へ出す

### 5. 報告する

- 詰めた要旨を 3〜5 行
- 更新したファイルのパス
- 次の選択肢（さらに `discuss` を続ける / `superpowers:writing-plans` が使えるなら設計フェーズへ / 一旦保留）

**勝手に実装フェーズへ進まない。** 選択肢を出してユーザが選ぶまで待つ。

## やってはいけないこと

- **ID を勝手に付け替える / 新しい ID を切る** — `discuss` は既存 1 件を詰めるだけ
- **備考に日付つきの履歴を積む** — 追記先は詳細ファイルの `## 判定履歴`
- **詳細ファイルを `<feature-ideas>/` 以外の命名で作る** — 直下は `FI-` で始まる名前のみ
- **実装計画（`- [ ] Step N` 形式の手順書）を詳細ファイルに書く** — それは `docs/plans/` の役目。
  vault ディレクトリに置くと、蓄積した結果 vault の件数指標が信用できなくなる
