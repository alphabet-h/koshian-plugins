# Koshian Plugins

Claude Code プラグインのマーケットプレイスリポジトリ。

## インストール

```bash
/plugin marketplace add alphabet-h/koshian-plugins
```

## プラグイン一覧

| プラグイン | 説明 |
|-----------|------|
| [claude-nfd](plugins/claude-nfd/) | Nurture-First Development（NFD）ワークフロー — Knowledge Crystallization Cycle |
| [harness-kit](plugins/harness-kit/) | Generator-Evaluator パターンによる長時間開発ハーネス — マルチエージェント品質保証ワークフロー |
| [design-kit](plugins/design-kit/) | テンプレート駆動でデザイン用エージェントスキルを作成するメタスキル（UI Component / Brand Voice / Audit + 自作テンプレ対応、v0.1 は Web/IT 寄り） |
| [design-forge](plugins/design-forge/) | フリー入力 + Q&A 駆動でデザイン用エージェントスキルを作成するメタスキル（業種を問わない汎用版、design-kit の姉妹） |
